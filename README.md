# Platform Deck

Platform Deck — modern web platform techniques as offline flash cards. 251 cards in 17 categories, for macOS, iPhone and Apple Watch. No account, no tracking, no network.

- Web page: https://dcreations.fr/platform-deck/
- Privacy: https://dcreations.fr/platform-deck/privacy/ (the app collects no data)
- Releases: see the Releases page of this repo. The newest is marked "Latest"; older versions stay available.

## Build
1. Install Xcode 26 and XcodeGen (`brew install xcodegen`).
2. Run `xcodegen generate` in this folder.
3. Open the generated project, set your own signing team, and run.
